VFA EXISTING STUDENT PASSWORDS

The admin Students tab now has a "Generate Existing Passwords" button.

IMPORTANT: This feature intentionally does NOT run when "Save Students" is clicked.
It is a separate action because it resets the portal password for each existing student.

The button generates a new password for every saved student, updates that student's existing Supabase Auth account through the existing bright-api Edge Function, and displays the generated password in the Portal Password column and student record while the admin page is open. Student IDs, registration numbers, classes, grades, and student database records are not changed.

ONE-TIME DEPLOYMENT
The bright-api-index.ts source in this ZIP must be deployed to the existing Supabase Edge Function named "bright-api" before the new password-reset button can update existing Auth passwords. Do not create a new function and do not change the function name.

After deploying the updated function, log into the VFA admin portal, open Students, and click "Generate Existing Passwords". Confirm the warning.
